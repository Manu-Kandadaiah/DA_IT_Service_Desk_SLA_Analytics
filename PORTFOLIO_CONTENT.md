## Portfolio Description (100–150 words)
This project demonstrates an end-to-end service-desk analytics workflow using reproducible synthetic data for fictional Pi Systems Private Limited. I generated 20,000 linked IT support tickets covering 2025–2026, together with 1,500 employees, 25 technicians and 2,500 assets. Controlled data-quality issues—including duplicates, missing technician values, mixed date formats, inconsistent text and invalid CSAT values—were cleaned and documented using Pandas. The analysis measures SLA compliance and breaches, first-response and resolution times, backlog aging, technician workload, reopened tickets, customer satisfaction, category and department patterns, monthly trends and Pareto concentration. I used NumPy for conditional classification and outlier analysis, MySQL/SQL for business queries, Matplotlib for reporting and Excel for the executive dashboard. All findings are calculated from the generated dataset, and the project is explicitly portfolio/educational work rather than professional client experience.
